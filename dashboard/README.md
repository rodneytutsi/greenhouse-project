# Greenhouse Dashboard

This directory contains a lightweight dashboard for the Smart Greenhouse IoT system.

## Files

- `index.html` – dashboard layout
- `styles.css` – dashboard styling
- `app.js` – demo data rendering and chart setup

## How to open it

Because this is a static dashboard, you can open `dashboard/index.html` directly in a browser, or serve the folder with a simple local web server.

### Option 1: Open directly

Open the file in your browser:

- `dashboard/index.html`

### Option 2: Run a local server

From the project root:

```bash
cd dashboard
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## Current behavior

The dashboard currently uses demo data so it works immediately without a database or API connection.

## To connect to your MySQL app later

When your backend is ready, replace the demo arrays in `app.js` with API calls such as:

- `/api/readings?sensor_id=1`
- `/api/alerts?greenhouse_id=1`
- `/api/sensors?greenhouse_id=1`

Then render the same UI from live data.

## Notes

This is a front-end dashboard only. For a full live greenhouse system, the recommended next step is to add:

- a backend API (Node.js / Express or PHP)
- MySQL queries against `greenhouse_schema.sql`
- authentication and authorization
- live MQTT or polling updates for sensor readings

## Example live architecture

```text
MySQL database
   ↓
Backend API
   ↓
Dashboard frontend
```

If you want, the next step can be to add a complete live API and deployment setup for this dashboard.
